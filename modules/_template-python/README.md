# Hello (Python) template

Copy this folder to start a Python module. The default language for new modules is C# (`../_template/`). Use this one only for a Python tool.

Run alone: `launch.cmd [name]`. It prints a greeting and exits 0. Wrong arguments exit 2.

- Settings: `%APPDATA%\DeskKit\template-python\settings.json`, key `greeting` (default `Hello`). Written with defaults on first run.

Steps: `docs/module-contract.md`, section 14.
