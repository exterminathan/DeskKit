## Where the brief is wrong or stale

- **RegionShot path.** The folder is `D:\My Software\RegionShot`. The `.venv` was created at `D:\Software\RegionShot\.venv` (`pyvenv.cfg`), and the forwarder `C:\Scripts\region_shot.bat` sets `APP=D:\Software\RegionShot\RegionShot.bat`. `D:\Software` does not exist, so the PATH forwarder is broken today. The Taskbar shortcut works: it points at `D:\My Software\RegionShot\RegionShot.bat`.
- **RegionShot size.** `region_shot.py` is 2356 lines. Its own `CLAUDE.md` still says "~900 lines" and is out of date.
- **RegionShot has a hidden local HTTP API** (127.0.0.1, port from QSettings `api_port`). The brief does not mention it.
- **Region Control licence.** The brief says "type not checked". It is MIT, "Copyright (c) 2026 inNATE Tools". Region Control has no NuGet or other dependency (`RegionControl.csproj` lists none).
- **Region Control is .NET 8 WinForms** (`net8.0-windows`), so the .NET 8 shell choice matches. Release is self-contained, single-file, win-x64.
- **Region Control data location.** The app writes `%APPDATA%\RegionControl\` (`layouts.json`, `theme.json`, `logs\`). Its `CLAUDE.md` and `docs/g1-notes.md` say the app writes no files. That is out of date.
- **Region Control installed copy.** Autostart in HKCU Run points to `C:\Program Files\Region Control\RegionControl.exe`. The installer default is per-user (`{autopf}` under lowest privileges), so this copy came from an admin install.
- **LightweightTaskbarGroups** is not a repo with an installer. It has a `publish/` folder and a script. The repo has **no LICENSE file**. `C:\TaskbarGroups` is the live copy and `dotnet build` copies output there.
- **Eye Saver is not generic.** `monitor.ps1` is 50 lines and hard-codes one monitor (Samsung S34J55x) and DDC/CI profile values.
- **Cable Listen** is tkinter only (standard library). It has no pip dependency.

## Risks for the module contract

- **Path-bound modules.** Cable Listen, RegionShot and Eye Saver hard-code `C:\Tools`, `C:\ffmpeg`, `D:\Software` or the repo path. `module.json` must resolve helpers relative to the module folder, with a "find on PATH" fallback.
- **Three config models.** Region Control uses `%APPDATA%`, LightweightTaskbarGroups uses its exe folder, RegionShot uses QSettings (registry), and Eye Saver has none. A single `%APPDATA%\DeskKit\<module>\` rule needs a migration step and a code change in LightweightTaskbarGroups, RegionShot and Cable Listen.
- **Runtime needs differ.** Python modules need Python (Cable Listen 3.12, RegionShot 3.11 venv of about 235 MB). The contract must say who supplies each runtime: the user, an embedded Python, or a frozen build (which weakens the PySide6 LGPL position).
- **Run-mode mix.** A tray app (Region Control), a click-once script (Eye Saver), a pinned-shortcut popup (LightweightTaskbarGroups) and windows (RegionShot, Cable Listen) do not share one "toggle" meaning. The contract needs a run-mode field and an autostart flag. Only Region Control has autostart today.
- **Licences and notices are uneven.** LightweightTaskbarGroups, RegionShot, Cable Listen and Eye Saver (inside ClaudeGlobalSetup) have no LICENSE file. DeskKit is MIT, so each tool needs one before it joins. NirSoft's "no commercial product" clause and ffmpeg's GPL decide whether helpers ship inside the installer or download at install. Also: Eye Saver is tied to one monitor model, so as a module it needs a settings file for the DDC profile.
